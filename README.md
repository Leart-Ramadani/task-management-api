# Task Management Api

## 1. Project overview

Task management api is a REST API that allows users to create projects and manage tasks within those projects.

The project will be built using Node.js, Express, PostgreSQL and Prisma.

The purpose of this project is to practice backend development using Javascript and software development lifecycle from planning to deployment.

## 2. Problem
Developers and small teams need a simple way to organize projects and tasks programmatically through an API.

## 3. Goal
Build a small production-style REST API that supports:
- User authentication
- Project management
- Task management
- Task assignment
- Task status management
- Task filtering

## 4. Target Users
- Regural users
- Administrators

## 5. Project Scope
### In Scope
- User registration
- User login

- Task CRUD
- Task assignment
- Task filtering
- Authentication

- Validation

### Out of Scope

- Users can create and manage their projects.
- Users can create and manage tasks.
